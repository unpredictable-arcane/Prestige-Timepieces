# Prestige Timepieces

Prestige Timepieces is a luxury-themed static website crafted to showcase rare, vintage, and haute-luxe watches.  
It focuses on refined visuals, smooth animations, elegant typography, and a premium user experience — perfect for portfolio display or client presentations.

## ✨ Features

### ⭐ Premium Hero Section
- Full-screen background with slow zoom animation  
- Luxury-style heading & tagline  
- Crisp CTA button  

### ⭐ Interactive Sidebar Navigation
- Smooth hamburger animation  
- Slide-in drawer menu  
- Social icons included  

### ⭐ About Us (Luxury Grid Layout)
- 6 info blocks arranged in a responsive grid

- Ideal for enquiry & private viewings  

### ⭐ Smooth Animations & Loader
- Preloader spinner

- Image fade transitions

## 📞 Make Contact Form Functional

To activate the contact form, choose one of the following approaches:

### **1. EmailJS (Backend-Free)**
- Easiest way to send form data directly to your email.
- No server needed.
- Add the EmailJS script and form handling code in `script.js`.

### **2. Netlify Forms (Zero Setup)**
If hosting on Netlify:
- Add `netlify` attributes to your `<form>`
- Netlify will automatically capture submissions.

### **3. Custom Node.js Backend**
For full control:
- Create an Express server  
- Use Nodemailer to send emails  
- Deploy to Render / Railway / VPS
